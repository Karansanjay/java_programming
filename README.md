# Java Banner App

A simple Java console application that displays a welcome banner using formatted text.

## Features
- Displays a welcome message
- Uses Java's `System.out.println()`
- Beginner-friendly program

## Technologies Used
- Java
- Basic console output

## Output
```text
******************************
*                            *
*      WELCOME TO JAVA       *
*                            *
******************************
```

## How to Run
1. Download `BannerApp.java`.
2. Compile using `javac BannerApp.java`.
3. Run using `java BannerApp`.
